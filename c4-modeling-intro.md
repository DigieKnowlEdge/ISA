Attendees are strongly recommended to complete this lesson before beginning the ISA Training, to ensure you are prepared to complete all the modules.

## Objectives

Upon completion, attendee should be able to perform the following:

- Understand how to use the C4 Model for Software Architecture
- Understand C4 Modeling Basics
- Create a simple C4-model using MS Threat Modeling Tool
