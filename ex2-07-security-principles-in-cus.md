# Check whether security principles are observed in CUS

Find violations to any security principles, _report_ `CAVs` using `Mattermost`. Once `CAVs` are validated, _document_ it as `vulnerabilities` in the `ThreatCat`

## Metadata

| Property | Details |
|-|-|
| Setup | Group Exercise |
| Timing (on session) | 15 min |
| Timing (self paced) | 45 min |

## Objectives:

At the end of this exercise, attendee should be able to perform the following:
* apply security principles to find vulnerabilities and report it as CAV
* apply security principles to find vulnerabilities and document it in ThreatCat

## Additional Notes:

Security Principles define the foundation for all security related decisions

## Tasks

### Identify your first CAV (~15 min)
1. Analyse to _find_ any violation of `Security Principle` looking at the `System Architecture` using transcripts and your notes, and the C4/DFD.
2. Use the template provided below and articulate the CAV (Copy and paste the template on Mattermost, add CAV number and details in "input text here").
3. Submit on Mattermost and add your respective group labels. e.g "Group A - CAV"
  
```
| **Group ID - Threat ID: Title ** | Group A - 1: input your text here |
|-|-|
| **Vulnerability Description** | input your text here |
| **Threat Scenario** | input your text here |
| **Countermeasure** | input your text here |
| **Severity** |low / medium / high / critical|
```

!!! note
    The Objective: apply security principles to find vulnerabilities


###  Find more CAVs (~30 min)
1. _Repeat_ the task above to _find_ at least 2 more `vulnerabilities`
2. _Review_ your `issues` accordingly, considering Instructor or Moderator `comments` on Mattermost

### Document CAVs in ThreatCat (~15 min)
1. _Open_ ThreatCat and go to "Threats"
2. Use "Create threat" on the top right
3. Provide all needed data (threat name, vulnerability description &threat scenario)

!!! note
    You can keep the "Countermeasure" field empty and ignore all metrics related fields (this will be addressed in a following lesson and exercise)
