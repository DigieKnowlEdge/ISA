# Let’s play Elevation of Privilege (EOP) Game

This exercise, we will be identifying threats using the STRIDE Model via playing the Elevation of Privilege (EOP) game.
The EOP game is designed to be the easiest way to start looking at your design from a security perspective.
Participants work together to go over different types of Threats and explore different criticalities and examples to find CAVs.

| Property | Details |
|-|-|
| Setup | Group Exercise |
| Timing (on session) | 30 min |
| Timing (self paced) | n/a |

## Objectives

At the end of this exercise, attendee should be able to perform the following:
* Describe the various STRIDE categories and how they work
* Find CAVs using STRIDE
* Assess severity or criticality of threats they discover

## Additional Notes

Threats should be articulated clearly, testable, and addressable. In the event that a threat leads to an argument, the threat should resolve by asking the following questions:
* Would we take an actionable bug, feature request or design change for that?
  * If the answer is yes, it is a real threat.
> This doesn’t mean that threats outside of that aren’t real, it’s simply a way to focus discussion on actionable threats.
* Questions that start with “There’s a way” should be read as “There’s a way…and here’s how… ”
* Questions that start with “Your code” should be read “The code we’re collectively creating…and here’s how.”

## Tasks

### Analyze by playing EOP and Report CAVs finding (~20 min)
1. _Update_ your C4/DFD (both C2 and C3) to apply STRIDE-per-Element
2. As a group, _open_ a new `tab`/`window` and go to the [EOP Card Game](https://copi.owasp.org/games/new).
3. You will receive a link by the instructor you need to use as a team. If not already done, pick a user name like `Group A` and join the Game.
4. _Select_ any card you like
5. _Discuss_ if the threat on the card is applicable to CUS. If not, draw the next card.
6. If the `threat` is applicable, select it
7. Present your threat in the main room

###  Document CAVs as Findings in ThreatCat (~10 min)
1. _Open_ ThreatCat
2. Add any additionally found new threats
