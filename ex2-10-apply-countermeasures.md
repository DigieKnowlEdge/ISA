# Apply Countermeasures to Lower Risk

This exercise, you will apply countermeasures (mitigations) against your CAVs to lower the Risk or Rating.

## Metadata

| Property | Details |
|-|-|
| Setup | Group Exercise |
| Timing (on session) | 15 min |
| Timing (self paced) | n/a |

## Objectives

At the end of this exercise, attendee should be able to perform the following:
* Define Countermeasures (mitigations) 

## Additional Notes

You could apply more than one countermeasure for each CAV.
Make sure your mitigation is a **complete** solution

## Tasks

### Discuss Countermeasures with your group (10 min)

1. _Discuss_ and take notes of `countermeasures` available for each `CAV`
2. _Review_ your threat accordingly, considering Instructor or Moderator `comments` on Mattermost, if any
3. _Discuss_ as a group and use `ThreatCat` to _open_ and _update_ the following:
  * Go to the "Threats" section
  * Select all given threats and add a countermeasure. You can also add multiple countermeasures: 1) Implement ... 2) Monitor ...
  * One countermeasure can be marked as "mitigated" (all others can be kept open or unmitigated)

!!! note
    Mitigated means that the threat is sufficiently addressed or all relevant countermeasures are implemented. If only one of multiple countermeasures are implemented the whole threat can **not** be marked as implemented.


### Request Alice Entitlement (5 min)

!!! note
    This step is only needed for the end of the next exercise


!!! warning
    It may take up to 15 mins until this role is actually applied in ThreatCat


1. Open [Alice INT](https://alice-int.mercedes-benz.com/)
2. Go to "New Request" and select "Request for Myself"
3. Search for the role "INFORMATION_SECURITY_ARCHITECT"
4. Select the "INFORMATION_SECURITY_ARCHITECT" role (Hint **NOT** the AGP_SHOPFLOOR_...) and select "Next"
5. Add Validity from today till the end of the month (let's take least privilege seriously ;) ) and select "Next"
6. As reason add "ISA Training Participant" and select "Next"
7. Review and select "Submit Request"
8. Go to back to ThreatCat an continue from there
