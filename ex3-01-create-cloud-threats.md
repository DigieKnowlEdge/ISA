# Create Cloud Threats 

In this exercise, attendee will do the **Cloud Assessment** using ThreatCat with AWS template. By using template for selected Cloud Service Provider (CSP), we can focus on **Security IN in the Cloud** leveraging on shared responsibility model.

## Metadata

| Property | Details |
|-|-|
| Setup | Group Exercise |
| Timing (on session) | 10 min |
| Timing (self paced) | n/a |

## Objectives

At the end of this exercise, attendee should be able to perform the following:
* Identify and rate credible attack vectors for cloud threats

## Additional Notes

Security IN the cloud:
* Part 1: Familiarize yourself with the Vulnerabilities and controls of all cloud threat categories.
* Part 2: See if any of your previously found vulnerabilities lead to any “cloud” CAVs, and rate them

We will be using **AWS** Template for this exercise.

## Tasks

### Perform Cloud Assessment (10 min)

1. Go to "Cloud Assessment" 
2. Select AWS and "Apply Template" - confirm with "Apply"

!!! warning
    The template does not substitute an evaluation - it simply reduces the necessity to ask the cloud providers for all needed details.


1. Go to "Provider Questionnaire" and mark existing "Todo" fields in RC02 & RC18 as "Not_relevant".
2. Go to "Project Questionnaire"
3. Go to "RC02 Data Extract API" and mark both existing "Todo" fields as "Insufficient" and add a short explanation like "not yet implemented" and "must be evaluated"
4. Mark ALL other "Todo" field as "Sufficient" (so that the Questionnaire Progress gets 100%)
5. Go to "Summary & Actions" and "Generate Cloud Threats"
6. Go to "Threats", make sure to "Show Cloud Threats" 
7. Mark both cloud threats as "Mitigated"
