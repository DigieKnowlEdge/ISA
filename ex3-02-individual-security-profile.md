# Create an individual copy and create your first Security Profile

## Metadata

| Property | Details |
|-|-|
| Setup | Group Exercise |
| Timing (on session) | n/a |
| Timing (self paced) | 20 min |

## Objectives

At the end of this exercise, attendee should be able to perform the following:
* Copy an existing project
* Make their own adjustments
* Finalize their own Security Profile

## Tasks
Complete the following tasks:

### Create your own SP copy (~5 min)
1. Go to ThreatCat - Projects (which lists all projects you are connected with)
2. Create a duplicate of your group's project by simply clicking the "Duplicate" button
3. The Project name should contain your name (e.g. "Car Update Service - John Doe")

### Add you own CAV (~15 min)
1. Open your project and go to "Threats"
2. Add your own complete CAV (try to use the tools and libraries we learned about) 

!!! note
    Complete CAV means: Threat name, Vulnerability description, Threat scenario, Countermeasure, Base Metrics (all relevant ones)


### Submit your first individual SP
1. Review if all elements are done: 
   1. DFDs (Context, Container, Components)
   2. Cloud Assessment (no questions unanswered)
   3. Threats (all threats have a score and a countermeasure description, at least one threat is mitigated)
   4. Overview - Properties are aligned with the actual project info (Info-Classification, ISO, etc.)
2. Go to "Project Version" and select "Submit"
3. Go to Mattermost and create a message informing about your completion by adding your project link to the message (e.g. ```https://threatcat-training.i.mercedes-benz.com/projects/8/versions/34```)
4. Submit the message and wait for feedback. If it is negative, please improve and update the initially created message via another comment
