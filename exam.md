# Exam 

This instruction will help you performing the final exam

## Metadata

| Property | Details |
|-|-|
| Setup | Group Exercise |
| Timing (on session) | 120 min |
| Timing (self paced) | n/a |

## Before starting

!!! warning
    If not already done, please request the Alice INT entitlement to submit projects as this is later needed. See [Exercise 2-10](ex2-10-apply-countermeasures.md).


## Tasks

### Read the case study (~15 min)
1. Go to the [ThreatCat Training Environment](https://threatcat-training.i.mercedes-benz.com/) and open your exam project (which will be assigned to you **just at exam start**)
2. Go to the "General" tab and read the case study.

!!! note
       If you like, you can copy the description to any other editor of your choice.


### Perform the C4 Modeling exercise (~45 min) [8 Points]

1. Go to Context and fill in all missing "???" fields (i.e. entities & paths)

!!! note
       - If a field is empty, you can leave it empty
       - It is not necessary to add another entity or path (even though you consider it helpful)


2. Go to Container and fill in all missing "???" fields (i.e. entities & paths)

!!! note
       Same notes as above apply!


3. Go to Components, fill in all missing "???" fields **AND ADD MORE COMPONENTS**
   
!!! warning
       It is not sufficient to simply keep the existing components you need to add more!

   
!!! note
       If you are wondering which these components may be, review the "Functional Requirements" - each business function, must be covered by a component (e.g. if the solution allows to upload videos - there must be an "upload" component)


### Threat model the solution (~45 min) [9 Points, 3 per CAV]
1. Go to Threats and select "Create threat" (alternatively you can also use the "Threats" section in DFD mode)
2. Provide the following fields:
   1. Threat name
   2. Vulnerability description
   3. Threat scenario
   4. Countermeasure

!!! note
       All other fields (incl. the Base Metrics) are optional!


3. Provide 3 CAVs
4. You can provide another CAV (i.e. overall 5) which is **optional**, but taken into account if needed (e.g. if another CAV uses obviously wrong assumptions, like "No CSR is nominated")

### Solve the ISA dilemma (~15 min) [3 Points]
1. Got to Threats and open the Threat named "Final Exercise - The ISA Dilemma"
2. Read the details in the Vulnerability description
3. Provide your result in the Threat scenario
4. Make your suggestions in the Countermeasures
5. Leave the rest as-is (i.e. no need to change the status, type of threat or metrics)
6. Save the result

### Submit & Inform the instructors when you are done
1. Submit your result via: Project Versions > Submit > Provide Reason ("ISA Exam") and agree the checkmark > Submit
2. Reach out to one of the instructors (e.g. via Mattermost) and inform them when you are done
3. The instructor will review and let you know that you can leave

!!! note
    If you are done earlier and got the confirmation to leave, you do not need to wait until everyone is done.
    Usually at the end of the exam time (i.e. after 120 mins) it may take some time to be able to perform the review, please be patient


### Provide Feedback
1. Open the following link and provide your feedback: [Kahoot Feedback Survey](https://kahoot.it/challenge/007124700)

### Wait to receive the results
1. Be patient
2. Probably you need to be patient up to 2 weeks, then you will be informed via mail about the exam results
3. We are not sharing any details, but if you failed, you can request which area you need to improve until next time

## Some more info

* The exam is "open book" - you can use all resources you need (however, consider the next point!)
* Do not cheat (i.e. use someone elses answers)
* Do not use AI results without reviewing the AI's results 
* You need to reach at least 50% of the available points per exam part in order to pass 
* You need to pass all exam parts (i.e. C4, CAVs and Dilemma) to pass the exam (i.e. a great C4 will not be enough if your CAVs are bad) - **thus you need to timebox**"
* If you feel lost, please contact the instructors!
* You can leave your desk as you wish (e.g. for a bio-break)
* You do not need to share your screen, but it is suggested, this way we can help easier if needed
* You do not need to turn on your camera
